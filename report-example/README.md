# 报告示例

这三个文件是三个脚本对 `https://seogeo.cc` 真实运行生成的输出（小规模参数），让你在跑自己站点前先看到报告长什么样：

- `01-route-audit.md` — 路由体检（4 变体状态码表 + 3 问结论）
- `02-orphan-pages.md` — 孤岛/弱连接/埋太深清单
- `03-geo-check.md` — GEO 5 项检查 + AI 引用概率粗判

自己的站点用同样命令跑即可，见 [根目录 README](../README.md)。
